# PSD模板批量出图工具 MVP版本开发Roadmap

## 一、MVP版本核心功能范围
### ✅ 必须实现的核心功能
1. **用户体系**
   - 手机号/邮箱注册登录
   - 个人账号管理
   - 基础权限控制

2. **模板管理**
   - PSD模板上传（支持最大100MB文件）
   - MCP PSD解析插件对接，自动识别可编辑图层（文字层、图片层）
   - 模板基础信息配置（名称、分类、封面图）
   - 模板多尺寸规格绑定（支持自定义尺寸和预设常用尺寸）
   - 模板列表展示、搜索

3. **核心出图流程**
   - 模板选择
   - 替换文字填写、替换图片上传
   - MCP图片渲染插件对接，一键批量生成所有尺寸封面
   - 多尺寸预览页面
   - 批量打包下载ZIP压缩包

4. **历史管理**
   - 我的生成记录列表
   - 历史记录查看、重新下载
   - 模板收藏功能

### ❌ MVP暂不实现的功能（后续迭代）
- 在线精细化编辑功能（图层调整、文字样式修改等）
- 团队协作、模板共享功能
- 复杂PSD特效支持（仅支持标准图层）
- 付费、会员体系
- 小程序/APP端

## 四、上线里程碑
**MVP版本上线后核心能力：**
1. 用户可以上传自己的PSD模板，系统自动识别可编辑图层
2. 绑定模板需要的多个尺寸规格
3. 每次出图仅需输入替换文字、上传替换图片，一键生成所有尺寸
4. 批量下载生成的封面图
5. 所有生成记录和模板收藏保存在账号下可随时查看

**可满足的核心需求：**
解决用户"固定模板多尺寸批量出图"的核心痛点，效率提升10倍以上。
