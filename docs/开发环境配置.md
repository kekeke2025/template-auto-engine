## 四、启动方式

### 前端
```bash
cd frontend
npm run dev
```

### 后端
```bash
cd backend
npm run start:dev
```

> Windows PowerShell 如果报执行策略错误，用 node 直接调用 CLI：
> ```
> node node_modules/@nestjs/cli/bin/nest.js start --watch
> node node_modules/vite/bin/vite.js
> ```

## 五、字体配置

渲染文字需要系统安装对应字体。

| 常用中文字体 | 文件名 | 说明 |
|-------------|--------|------|
| 微软雅黑 | msyh.ttc / msyhbd.ttc | Windows 系统默认 |
| 宋体 | simsun.ttc | Windows 系统默认 |
| 黑体 | simhei.ttf | Windows 可选安装 |

> 字体匹配服务：`backend/src/template/font-matcher.service.ts`
> 匹配规则：模糊匹配字体名 → 映射到系统实际字体文件路径

## 六、环境变量

后端环境变量在 `backend/.env` 或 `app.module.ts` 中配置：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| PORT | 3002 | 后端服务端口 |
| DB_HOST | localhost | 数据库地址 |
| DB_PORT | 3306 | 数据库端口 |
| DB_USERNAME | root | 数据库用户名 |
| DB_PASSWORD | 123456 | 数据库密码 |
| DB_DATABASE | psd_template | 数据库名 |
| JWT_SECRET | （代码内） | JWT 签名密钥 |

## 七、重置测试账号密码

如果忘记了妈咪账号的密码，可以直接在数据库里重置：

```sql
-- 方式1：更新密码（需先用 bcrypt 生成 hash）
UPDATE users SET password = 'bcrypt_hash_xxx' WHERE id = 3;

-- 方式2：直接用 test 账号登录（密码 test123）
```

或者临时加一个重置接口（不推荐，开发完删掉）。
