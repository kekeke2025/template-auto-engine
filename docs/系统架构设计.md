# PSD模板批量出图工具 系统架构设计

## 一、整体技术架构分层
### 1.1 前端层（用户交互端）
#### 技术选型：
- **框架：React 18 + TypeScript**
- **UI组件库：Ant Design / Arco Design**
- **在线画布引擎：Fabric.js** - 实现画布渲染、图层操作、拖拽、缩放、属性调整等核心编辑能力
- **状态管理：Redux Toolkit / Zustand**
- **构建工具：Vite**
- **多端支持：响应式设计，适配PC端、平板端

#### 核心模块：
- 模板库页面：模板分类、搜索、收藏
- PSD模板上传配置页：PSD上传、图层识别、可编辑层配置、多尺寸绑定
- 快速生成页：模板选择、文字填写、图片上传、一键生成
- 预览调整页：多尺寸预览、单图编辑入口
- 在线编辑器：画布操作、图层列表、属性调整面板
- 用户中心：我的生成记录、我的收藏、账号管理

---

### 1.2 后端服务层
#### 技术选型：
- **主语言：Node.js / Python（FastAPI）**
- **Web框架：NestJS（Node.js）/ FastAPI（Python）**
- **微服务拆分：
  - 用户服务：账号、权限、收藏、生成记录管理
  - 模板管理服务：PSD上传、图层解析、模板存储、分类管理
  - 图片处理服务：批量渲染、图片导出、压缩打包
  - 在线编辑服务：图层操作实时同步、编辑历史保存

---

### 1.3 核心能力层（依赖第三方服务/MCP插件）
#### 1.3.1 PSD解析能力
**可选方案：
1. **自研：基于`psd.js`开源库** - 前端/后端都可以解析PSD文件，提取图层信息、文字样式、图片资源
2. **第三方MCP插件：PSD解析服务** - 稳定的商业化PSD解析能力，支持复杂图层、特效、字体识别
3. **Adobe Photoshop API** - 官方API，解析能力最强，但成本较高

#### 1.3.2 图片渲染导出能力
**可选方案：
1. **自研：基于`Sharp` + `node-canvas`** - 后端批量渲染图片，支持导出PNG/JPG/WebP等格式
2. **第三方MCP插件：图片批量渲染服务** - 高并发批量渲染，支持复杂特效渲染
3. **无头浏览器渲染：Puppeteer** - 前端画布导出，效果与在线编辑完全一致

#### 1.3.3 存储服务
- **对象存储：OSS（阿里云/腾讯云）/ MinIO（私有部署）** - 存储PSD模板文件、用户上传图片、生成的封面图
- **数据库：MySQL + Redis** - 存储用户信息、模板元数据、生成记录、分类信息等

#### 1.3.4 其他辅助插件
- **字体管理服务：MCP字体插件** - 支持字体识别、自动匹配字体、商业字体授权
- **图片压缩服务：自动压缩导出图片，优化下载速度
- **CDN加速服务：静态资源、图片加速访问

---

### 1.4 部署架构
#### 标准SaaS部署方案：
- 前端：静态资源部署到CDN
- 后端服务：容器化部署（Docker + Kubernetes）
- 存储：云对象存储 + 云数据库
- 弹性扩缩容：根据并发量自动扩容图片处理服务

#### 私有部署方案：
- 前后端都部署在企业内部服务器
- 存储使用内部MinIO对象存储 + 内部数据库
- 不依赖外部第三方服务，数据完全隔离

## 三、核心流程技术实现逻辑
### 3.1 PSD模板上传流程
1. 用户上传PSD文件 → 前端分片上传到对象存储
2. 调用PSD解析服务 → 解析图层信息，区分文字层、图片层、装饰层
3. 前端展示识别出的可编辑图层 → 用户配置哪些图层允许替换
4. 用户绑定该模板对应的多尺寸规格 → 保存模板元数据到数据库

### 3.2 批量出图流程
1. 用户选择模板 → 输入替换文字、上传替换图片
2. 提交生成请求 → 后端根据模板配置，为每个尺寸生成对应的图层参数
3. 调用图片渲染服务 → 批量生成所有尺寸的封面图
4. 生成预览图返回前端 → 用户预览效果

### 3.3 在线编辑流程
1. 用户点击单图编辑 → 前端加载Fabric.js画布，渲染对应尺寸的图层
2. 用户调整图层属性（位置、大小、颜色、透明度等）→ 实时同步到后端
3. 确认修改后 → 重新渲染图片，更新生成记录

### 3.4 导出流程
1. 用户确认所有图片 → 后端将所有尺寸的图片打包成ZIP压缩包
2. 生成下载链接 → 用户下载到本地
3. 保存完整的生成记录到用户账号下，支持后续二次编辑
