# PSD模板批量出图工具 产品需求文档

## 一、产品背景与痛点
### 1.1 业务背景
当前内容生产场景中，不同栏目/内容板块有固定风格的封面图需求：
- 每个栏目对应多套不同尺寸的封面规格（适配公众号、小红书、抖音、微博、视频号等不同平台）
- 栏目持续更新时，封面图仅需要替换核心图片和文字内容，其他元素（装饰、字体效果、版式布局等）保持固定不变
- 现有工作流程需要手动修改每个尺寸的设计文件，重复工作量大、效率低下

### 1.2 核心痛点
- 重复劳动：同一内容需要手动适配N个尺寸，耗时耗力
- 一致性难以保障：手动修改容易出现不同尺寸版本样式不统一的问题
- 历史版本管理混乱：修改后的封面图没有统一的存储和复用机制

## 二、产品核心定位
一款面向内容运营、新媒体从业者的智能批量出图工具，通过PSD模板一键生成多尺寸封面图，支持在线精细化调整，大幅提升封面制作效率。

## 三、核心功能列表
### 3.1 模板管理模块
- **PSD模板上传**：支持上传提前整理好图层的PSD模板，系统自动识别可编辑图层（文字层、图片占位层、装饰元素层）
- **模板多尺寸绑定**：同一栏目模板可绑定该栏目需要的所有封面尺寸规格，一次上传多尺寸复用
- **模板分类**：模板支持按栏目、用途、风格等维度分类管理
- **模板收藏**：用户可收藏常用模板，在「我的收藏」中快速访问
- **模板库**：集中展示所有可用模板，支持筛选、搜索

### 3.2 批量出图模块
- **快速替换**：选择模板后，只需输入新的文字内容、上传替换的核心图片
- **一键生成**：系统自动根据模板规则，批量生成所有尺寸的封面图
- **预览页**：生成后展示所有尺寸封面的预览效果，支持快速查看

### 3.3 在线编辑模块
- **单尺寸精细化编辑**：点击任意尺寸封面，进入画布编辑界面
- **图层操作能力**：
  - 文字：修改内容、调整字体、颜色、大小、位置、透明度、换行排版
  - 图片：调整大小、位置、透明度、裁剪
  - 所有图层：支持层级调整、显隐控制
- 实时预览编辑效果

### 3.4 导出与历史管理
- **批量打包下载**：确认效果后，自动打包所有尺寸的封面图为压缩包下载
- **生成记录保存**：用户每次生成的封面方案都会保存在账号下，支持随时查看
- **二次编辑**：历史生成记录支持再次进入编辑修改，重新生成导出

### 3.5 用户中心模块
- 我的生成记录：历史所有出图记录管理
- 我的收藏：收藏的模板管理
- 账号信息管理

## 四、核心使用流程
1. 上传PSD模板 → 配置可编辑图层 → 绑定对应尺寸规格 → 归入分类
2. 用户选择需要的模板 → 输入替换文字、上传替换图片 → 一键生成所有尺寸封面
3. 预览生成效果 → 按需对个别尺寸进行精细化调整
4. 确认后打包下载所有尺寸封面
5. 生成记录自动保存，支持后续再次编辑修改

## 五、用户价值
- 效率提升：原本需要1小时的多尺寸封面制作，缩短到5分钟完成
- 一致性保障：所有尺寸基于同一模板生成，样式保持100%统一
- 降低门槛：无需专业设计技能，运营人员即可独立完成封面制作
- 资产沉淀：所有模板和生成记录统一管理，方便复用和回溯
