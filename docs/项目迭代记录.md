# PSD模板批量出图工具 项目全记录
---
## 📌 一、项目概述（Pre）
### 1.1 项目背景
面向内容运营、新媒体从业者、电商设计人员，解决多平台尺寸封面重复制作的痛点：同一个内容需要同时适配公众号、小红书、抖音、视频号等多个平台的不同尺寸，重复劳动效率低。
### 1.2 核心价值
通过上传PSD模板，自动解析图层，绑定多尺寸规格，一键替换内容批量生成所有平台的封面图，制作效率提升80%以上。
### 1.3 目标用户
- 新媒体运营人员
- 电商美工
- 内容创作者
- 设计团队
### 1.4 技术栈
| 端 | 技术栈 |
|------|------|
| 前端 | React 18 + TypeScript + Vite + Ant Design + Zustand |
| 后端 | NestJS + （可选：MySQL + Redis + MCP插件） |
| 核心能力 | PSD解析、多尺寸批量渲染、图片打包下载 |

## ❌ 三、开发问题&解决方案记录
| 问题类型 | 问题描述 | 解决方案 |
|------|------|------|
| 环境问题 | Windows PowerShell默认禁止npm执行脚本 | 1. 用CMD运行 2. 执行`set-ExecutionPolicy RemoteSigned`修改权限 |
| 跨域问题 | 前端请求后端接口报CORS错误 | 后端CORS配置修改为`origin: true`，允许所有来源请求 |
| 端口冲突 | 3000/3001端口被其他程序占用 | 前端端口改为5173，后端端口改为3002 |
| 数据库依赖问题 | 开发阶段需要安装MySQL才能启动后端 | 移除数据库依赖，所有数据改用Mock模拟，零依赖即可启动 |
| 登录问题 | 前端登录报Network Error | 修复后端CORS配置，确保前后端都正常启动 |
| 路由问题 | 新增页面无法访问 | 补充App.tsx中的路由配置，完善路由守卫逻辑 |

## 📋 四、核心流程说明
### 4.1 【使用模板生成图流程】
```mermaid
graph LR
A[登录系统] --> B[模板列表选择模板]
B --> C[进入生成页，替换文字/图片内容]
C --> D[点击一键生成所有尺寸]
D --> E[查看各尺寸生成结果预览]
E --> F[单张下载/打包下载所有图片]
```
### 4.2 【上传自定义模板流程】
```mermaid
graph LR
A[点击上传模板] --> B[拖拽上传PSD文件]
B --> C[系统自动解析PSD所有图层]
C --> D[勾选允许用户编辑的图层]
D --> E[添加需要生成的多尺寸规格]
E --> F[填写模板名称、分类、封面]
F --> G[保存模板，自动加入模板列表]
```
### 4.3 接口清单
| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/auth/login` | POST | 账号登录 |
| `/api/auth/register` | POST | 账号注册 |
| `/api/template` | GET | 获取模板列表 |
| `/api/template/:id` | GET | 获取模板详情 |
| `/api/template` | POST | 保存新模板 |
| `/api/template/:id/generate` | POST | 批量生成图片 |
